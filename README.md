## Daily Commit Habit

Every study session produces at least one concrete artifact committed cleanly to `main`:
1. Summarize the core concept or problem in Markdown (`elements-of-ai/`, `ibm-skillsbuild/`, or `anthropic-academy/`).
2. Implement and run any code exercises locally (`python ...`).
3. Append a concise entry under `daily-log/YYYY-MM-DD.md` noting what changed and what is next.
